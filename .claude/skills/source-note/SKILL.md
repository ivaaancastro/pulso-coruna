# Nota de fuente

Crea `docs/sources/<fuente>.md` con: URL y fecha de verificación; método de acceso (clave, límites); licencia o términos de uso y atribución requerida (cópiala literal si hay texto, si no pon «no localizada»); frecuencia real de actualización medida; una respuesta de ejemplo recortada; riesgos.
Si la licencia o los términos no están claros, NO decidas: márcalo como «pendiente de decisión humana». No contactes con terceros.
