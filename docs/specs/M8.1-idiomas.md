# M8.1 — Idiomas gl/es/en

- Estado: implementada
- Rama: `feat/M8.1-idiomas`
- Referencia: `docs/ROADMAP.md` M8.1, `docs/design/` (tokens), `apps/web/src/i18n/`

## Problema y objetivo

La web ya tiene tres catálogos (`es`, `gl`, `en`) y detecta el idioma, pero faltan: una auditoría que garantice que no queda texto visible o accesible fuera de i18n (y que siga así), `<html lang>`, `<title>` y meta description acordes al idioma, un selector de idioma accesible y una revisión de calidad de gl y en. Criterio de aceptación del roadmap: «ninguna cadena fija en el código; gallego por defecto si se pide».

## Alcance

Dentro (solo `apps/web` y docs, sin dependencias nuevas): auditoría y migración de literales; test automático anti-literales; metadatos dinámicos; manifiesto por idioma; selector de idioma; revisión de gl/en; capturas.

Fuera: traducir `docs/`, nombres propios y fuentes (Puertos del Estado, aisstream…), contenido que llega de la API (nombres de barcos, paradas), contenido de teselas del mapa.

## Diseño

- **Auditoría.** Se revisaron textContent/innerHTML, `aria-*`, `title`, `alt`, `placeholder`, errores mostrados, tarjetas de capas, `index.html`, manifiesto y mocks. Único literal visible encontrado: la atribución del aire («Open-Meteo.com (datos CAMS)», `live/air/model.ts`) → clave `air.attribution`. El resto ya usaba `t()`. Quedan, justificados, las atribuciones legales del mapa (nombre oficial del titular), nombres propios (Torre de Hércules, estaciones), símbolos (`°`, `×`, `kn` va en clave), mensajes de consola/`Error` (no se muestran) y `live/dev/**` (solo desarrollo, fuera del build).
- **Test anti-literales** (`i18n/no-literals.test.ts`): recorre con la API de TypeScript (ya devDependency) todos los `.ts` de `apps/web/src` (salvo tests, `i18n/` y `live/dev/`) y falla si (a) un literal se asigna a un destino visible (`textContent`, `innerText`, `title`, `alt`, `placeholder`, `setAttribute("aria-label"|…)`, propiedades `text|label|title|kicker|message|note|name`, argumentos de texto de `el()`), o (b) un literal «parece prosa» (≥ 2 palabras alfabéticas o acentos/ñ) fuera de contextos ajenos a la UI (`import`, `console.*`, `Error`, tipos, comparaciones). Lista de excepciones por archivo + texto con motivo. También comprueba `index.html` y el manifiesto contra el catálogo `es`.
- **Metadatos.** `main.ts` fija `document.documentElement.lang`, `document.title` y `<meta name="description">` desde `t()`. `index.html` lleva el valor por defecto (es) para quien no ejecuta JS o para scrapers. Manifiesto: `manifest.webmanifest` (es) + `manifest.gl.webmanifest` y `manifest.en.webmanifest` (misma `id`, `name`, `icons`; solo cambian `lang` y `description`); `main.ts` apunta el `<link rel="manifest">` al de su idioma. Limitación: el manifiesto lo lee el navegador al instalar, así que la PWA instalada conserva el idioma con el que se instaló; la UI sigue el idioma de cada sesión. Un test garantiza que las tres variantes no divergen.
- **Selector** (`components/language-selector.ts`): botón con el idioma actual (GL/ES/EN, `aria-label` «Idioma: Galego», `aria-expanded`) que despliega un grupo etiquetado con tres opciones (`aria-pressed`, `lang` propio, nombres en su idioma: Galego, Castellano, English). Teclado: Tab/Intro/Espacio; al abrir el foco va a la opción activa; Escape o clic fuera cierran y devuelven el foco. Posición: a la izquierda de «Compartir» (arriba en móvil; abajo a la derecha en escritorio, porque arriba vive la etiqueta de aire; el primer intento, tres botones siempre visibles, chocaba con «Compartir» y la hora en 390 px). Objetivo táctil `--pulso-touch`, foco `:focus-visible` global, solo tokens de diseño. Al elegir, guarda el idioma en `sessionStorage` (solo de sesión; falla en silencio si no hay) y recarga con `?lang=xx` conservando el resto de parámetros y el hash (la cámara y el modo compartidos). Recargar es lo mínimo (cero re-renderizado en vivo, cero bytes en el JS diferido). Prioridad de `detectLocale`: `?lang=` → sesión → `navigator.languages` → es.
- **Fechas/horas.** Ya usan `INTL_LOCALE[locale]` con `timeZone: Europe/Madrid`; sin cambios. `time/day.ts` y los mocks usan `en-GB` solo como formato técnico interno, nunca visible.
- **Calidad gl/en.** Revisión terminológica completa (ver PR): gl sin castellanismos obvios (se mantiene «Hai», «Móstrase o gardado», «Ocos libres», «Escoitar»); en: «Aircraft» unificado entre tarjeta y estado de capas.
- **Presupuesto.** Todo vive en el JS inicial (≈ 10 KB gzip frente a 250); el JS diferido (557,2/560 KB) no puede crecer. Medido con `pnpm perf:bundle`.

## Criterios de aceptación

- [x] Ninguna cadena visible o accesible fuera de i18n; un test falla si aparece una nueva.
- [x] `<html lang>`, `<title>` y meta description dinámicos; manifiesto por idioma o limitación documentada.
- [x] Selector accesible gl/es/en (teclado, aria, tokens, táctil ≥ 44 px), persistencia solo de sesión + `?lang=`.
- [x] Gallego por defecto si se pide (`?lang=gl` o navegador `gl`).
- [x] JS diferido ≤ 560 KB gzip.
- [x] Capturas `docs/design/capturas/m8-1-*.png` (390×844 y 1440×900, gl/es/en).

## Plan de pruebas

Unitarios (`i18n`, `language-selector`, manifiesto, anti-literales); `pnpm -r typecheck test lint`, `pnpm format:check`, `pnpm perf:bundle`; navegador real en 390×844 y 1440×900 con `?lang=gl|es|en`, teclado y recarga.

## Riesgos y decisiones

- Cambiar de idioma recarga la página (pierde Reproducir en curso, salvo lo que ya vaya en el hash). Aceptado por simplicidad y peso.
- Manifiesto en tres archivos: riesgo de deriva, mitigado por test.
- El test heurístico puede dar falsos positivos: se añaden a la lista de excepciones con motivo.
