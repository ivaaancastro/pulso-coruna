# ADR-0012: PWA con service worker propio y sharp para los iconos

- Fecha: 2026-11-18
- Estado: aceptada

## Contexto

M2.6 hace la web instalable y utilizable sin conexión. El SW no debe añadir JS inicial apreciable y las teselas PMTiles (~7 MB) se piden con `Range`.

## Decisión

SW a mano (~3 KB, sin Workbox), empaquetado por un plugin de Vite mínimo a `dist/sw.js` con precaché del shell y versión por hash del build; el registro es un `import()` diferido solo en build de producción. Teselas: la Cache API no guarda respuestas 206, así que se cachea el fichero completo una vez (petición sin `Range` en segundo plano) y las peticiones `Range` se sirven recortando el blob cacheado; sin caché, pasan a red intactas. API y WebSocket nunca se cachean. Iconos PNG generados desde `apps/web/icons/icon.svg` con `sharp` 0.34.5 (devDependency fijada, solo para `pnpm --filter @pulso/web icons`; los PNG se versionan).

## Alternativas

`vite-plugin-pwa`/Workbox (peso y dependencias); PNG a mano (no reproducible desde el SVG); cachear por tramos (complejo y frágil con `Range`).

## Consecuencias

Actualizar teselas exige cambiar `TILES_CACHE` en `sw-logic.ts`. Nueva versión del shell = aviso discreto y recarga al aceptar.
